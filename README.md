# RAG Document Chatbot

A Retrieval-Augmented Generation (RAG) chatbot that lets you upload your own documents and ask natural-language questions about them. Instead of relying only on an LLM's built-in knowledge, this app retrieves the most relevant chunks of your documents and feeds them to the model as context, producing grounded, accurate answers with fewer hallucinations.

## Features

- Upload plain text or PDF documents
- Automatic chunking and embedding of document content
- Semantic search over embeddings using a vector store (FAISS)
- Context-aware answers generated by an LLM (OpenAI API)
- Simple, interactive Streamlit chat interface
- Modular code so the embedding model, vector store, or LLM can be swapped easily

## Architecture

1. Documents are loaded and split into overlapping text chunks.
2. Each chunk is converted into a vector embedding.
3. Embeddings are stored in a local FAISS vector index.
4. When a user asks a question, the question is embedded and compared against stored chunks to retrieve the most relevant ones.
5. Retrieved chunks are passed to the LLM along with the question to generate a final answer.

## Tech Stack

- Python 3.10+
- Streamlit (UI)
- OpenAI API (embeddings and chat completion)
- FAISS (vector similarity search)

```

├── app.py              # Streamlit UI entry point
```

## Setup

1. Clone the repository:

```
git clone https://github.com/Saikalyani-Y/rag-document-chatbot.git
cd rag-document-chatbot
```

2. Create a virtual environment and install dependencies:

```
pip install -r requirements.txt
```

3. Copy .env.example to .env and add your own OpenAI API key:

```
cp .env.example .env
```

4. Run the app:

```
streamlit run app.py
```

## Usage

- Launch the app and upload a document (or use the provided sample in sample_docs/).
- Type a question about the document's content in the chat box.
- The chatbot retrieves relevant context and returns an answer grounded in your document.
